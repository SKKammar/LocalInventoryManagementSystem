## About

This project is a Java-based Inventory Management System designed to help small businesses manage their products and inventory.  
It provides basic operations such as adding, editing, deleting, and viewing products, along with stock tracking.

---

## Features

- Add new products  
- Update product details  
- Delete products  
- View product list and details  
- Track inventory quantities
